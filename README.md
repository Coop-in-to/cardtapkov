# Tarkov Card Collection

Made some cards based on Tarkov. Just for fun, for myself, tested different neural networks. Everything in one style.

Inside — 1500+ cards. Rarities from common to mystical. There are collections by faction: BEAR, USEC, scavs, bosses and others — 13 collections in total, 9 booster packs, but you can't really pull the interesting cards from them.

You open boosters — you get cards. You collect, you fill your albums. Simple as that.

If you like it — I'll be happy. If something's off — let me know, we'll fix it.

P.S. there are 13 collections, in 1 zip archive, unpack before adding
